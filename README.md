advanture camp
Adventure Camp adalah program penyewaan peralatan camping berbasis bahasa pemrograman C. Program ini dibuat untuk memudahkan pengguna dalam melihat daftar peralatan camping, melakukan penyewaan, menghitung biaya sewa berdasarkan jumlah barang dan lama penyewaan, serta mendapatkan diskon sesuai durasi sewa. Program ini juga menyediakan fitur struk pembayaran dan riwayat transaksi untuk melihat data penyewaan serta total pendapatan.
